# To-Do App 
A simple To-Do application built with Flask and Python. This project is my part of practice which helping me to learning web-development with Python, working with Flask, integration of database and templates of html.

## Technologies Used:
- Python--application logic
- Flask--web framework
- Flask-SQLAlchemy--database integration
- SQLite--database
- HTML--page structure

## Getting Started
### 1. Clone the repository
        git clone https://github.com/Asadullah-Mim/todo-app.git
        cd todo-app

### 2. Create a virtual environment
        python -m venv .venv

### 3. Activate the virtual environment
        On Windows Powershell:
        .venv\Scripts\Activate.ps1

### 4. Install dependencies
        python -m pip install -r requirements.txt

### 5. Run the application
        flask --app app run

Open the local address shown in your terminal, usually http://127.0.0.1:5000/, in your browser.

**Note:**
The repository contains the application code and dependencies. You may need to initialize the database according to the setup in app.py before running the app for the first time.
